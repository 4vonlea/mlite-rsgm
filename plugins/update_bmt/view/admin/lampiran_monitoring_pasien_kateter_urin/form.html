Petunjuk Pengisian Formulir Monitoring Kateter Urin (PPI):
  • Diisi oleh Perawat: Pemantauan dilakukan setiap hari selama kateter urin menetap terpasang pada pasien rawat inap.
  • Item Pencegahan ISK: Beri tanda ✓ (centang) bila dilakukan, atau tanda - (strip) bila tidak dilakukan.
  • Gejala ISK: Beri tanda ✓ bila ditemukan gejala sesuai kriteria, dan tanda 0 bila tidak ditemukan gejala.
  • Gunakan tombol cepat "Set Semua ✓ (Dilakukan)" atau "Set Gejala 0 (Normal)" untuk kemudahan pengisian harian.
