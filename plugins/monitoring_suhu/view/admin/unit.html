Kelola Unit & Hak Akses Monitoring Suhu

Buat unit/rumahan monitoring (misal: Unit Laboratorium, Unit Server IT, Unit Farmasi) dan tentukan pengguna yang berhak mengelola & mengisi di masing-masing unit.

Kembali ke Monitoring
Cara Kerja Hak Akses Per Unit:
  1. Admin membuat Unit (rumahan), misalnya Unit Laboratorium, Unit Server IT, atau Unit Farmasi.
  2. Admin menugaskan pengguna yang berhak pada masing-masing unit (hak akses modul monitoring_suhu otomatis disinkronkan).
  3. Pengguna unit dengan hak Pengisi & Kelola Titik Ukur dapat menambahkan sendiri Ruangan / Kulkas / Freezer / Inkubator di unitnya (memilih ukur Suhu saja, Kelembaban saja, atau Keduanya) lalu menginput nilai hariannya.
